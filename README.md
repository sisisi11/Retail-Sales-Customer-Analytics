# Retail Sales & Customer Analytics

A practical end-to-end portfolio project that follows synthetic retail data from raw CSV files to a SQL Server reporting layer and a Power BI dashboard.

The fictional retailer sells through physical stores and an online channel. The data covers customers, products, stores, sales, sale items, promotions and returns.

## Planned Data Pipeline

**Raw CSV files -> Python and pandas -> SQL Server staging tables -> clean relational model and reporting views -> Power BI**

## Business Questions

- How do revenue and order volume change over time?
- Which products, categories and stores perform best?
- How do online and in-store sales compare?
- Who are the highest-value and repeat customers?
- What is the return rate by product and category?
- How do promotions relate to sales performance?

## Current Dataset

The raw layer is generated by `src/generate_raw_data.py` with a fixed random seed. This keeps the project reproducible while providing enough data for meaningful SQL and Power BI analysis.

- 401 customer rows, including one intentional duplicate
- 36 products across six categories
- 5 physical stores
- 6 promotions
- 2,500 sales
- 6,206 sale items
- 496 returns

A small number of known quality issues are included so the future ETL stage can detect, report and reject invalid records instead of silently correcting the raw source.
